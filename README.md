# Shizukun Pro（滚木）

基于 Shizuku API 开发的安卓卫士学习项目。

> 项目状态：开发中 WIP，尚未正式出品。
> 本仓库仅存放源码、素材与开发文档，不提供编译好的 APK，仅供技术研究学习。

## 目录结构

```
.
├── app/                              # 主程序模块
│   └── src/main/
│       ├── java/com/shizukun/pro/    # Java 源码
│       ├── res/                      # 资源文件（布局/图片/字符串）
│       └── AndroidManifest.xml       # 清单文件
├── docs/                             # 开发笔记与文档
├── build.gradle                      # 项目构建配置
├── settings.gradle                   # 模块声明
└── README.md
```
